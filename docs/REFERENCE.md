# 功能与运行参考

## 工作台与渠道

工作台保留文本/参考图生成、参数调整、历史任务、预览和下载。图库只显示服务器上当前账号的作品。

先选择「站点默认渠道」或「自定义渠道」，再选择 OpenAI / Gemini 协议及渠道、模型。共享渠道由管理员维护，私有渠道只由本人管理。普通用户不能通过提交请求覆盖共享渠道的地址或密钥；后端只接受渠道 ID，并在受理时冻结当前配置。

模型目录来自渠道自身的 `/models` 接口，后台定时和管理者手动刷新；失败保留上次成功目录。兼容接口不保证提供模型列表，可由管理者手填模型 ID。共享模型必须显式启用，不自动选择所谓最新版本。模型目录也不能可靠说明图片输出、尺寸、质量或 thinking 的全部能力。

模板是管理员提供的参数预填，不是能力白名单。用户可继续修改已有协议字段；后端不再依据写死的模型 ID 抹掉参数。不支持的组合由上游返回错误，不擅自降低尺寸或替换模型。接口没有任意 JSON、Header 或供应商自定义扩展字段编辑器。

## 账号与权限

用户名为 3–64 位 ASCII 字母、数字、点、下划线或连字符；密码 12–1024 字符。注册必须使用有效邀请码，注册角色固定为普通用户。邀请码由管理员创建，可以无限次使用、无有效期、可撤销。

登录使用 HttpOnly 会话 Cookie；修改请求带 CSRF token。密码使用带盐 PBKDF2，不保存明文。API Key 使用服务端 AES-GCM 加密，不回传浏览器；图片等业务数据本身不做磁盘加密。

管理员可禁用普通用户、设置额度覆盖、重置普通用户密码、管理共享渠道和模板；不能在网页上提升角色或查看别人的提示词/作品/私有密钥。管理员创建与恢复使用 [部署命令](<DEPLOYMENT.md>)。禁用账号使会话失效，待执行任务停止；已开始的调用允许收尾。

## 额度和队列

日界线为 `Asia/Shanghai`。管理员设置默认日任务数，可给用户覆盖；空值继承，-1 无限，0 禁止。站点默认额度为空时共享生成关闭。一次任务（不是每张图）预占一次共享额度，私有渠道不预占共享额度。

失败总是退回原提交日一次，不论是否已经请求供应商；成功后删除任务或作品不退款。站内退款不代表供应商退款。重试是一个新任务，正常重新预占；同 UUID、同请求的确认/重放不会再次扣额度。

默认全站并发 2、单人并发 1、等待队列上限 100；管理员可调整。队列按受理顺序扫描，跳过已达到单人并发上限的用户，使其他用户仍可执行。

## 持久任务与恢复

提交的客户端字段为任务 UUID、提示词、渠道、模型、参数和可选参考图，不包含 API Key。接口详见 [新版 API 契约](<API_V2.md>)。

- 后端确认受理后，即使关闭页面，任务仍在服务器执行。
- 断线未确认的提交保留原 UUID，通过查询确认是否受理，不能盲目创建新付费请求。
- 提交后修改渠道地址、密钥、模型选项或模板，不改动原任务快照；终态删除快照中的凭据和参考图。
- 禁用账号/渠道或删除渠道会停止排队任务并退款；不会主动中断已在执行的调用。
- 生成图默认在本地；管理员可切换新图到私有 R2。切换不迁移旧图，R2 写失败时回退本地并生成管理员告警。对象保存后记录完成收据并提交数据库，重启可恢复，不重复请求生成。
- 无完成收据的运行中任务在重启后失败并退款，不能确定供应商是否已经收费；用户决定是否手动重试。
- 删除任务或图库组会删除该任务的全部图片；排队和运行中的任务不能删除。图片默认永久，也可由管理员按整天设置。到期立即隐藏整组并禁止读图；后台清理原位置的本地文件或 R2 对象，失败重试。已保存的图不随之后的策略变化改期。

## 边界与排查

生成请求最多 44 MiB JSON。OpenAI 参考图最多 16 张，单张 20 MiB、总量 32 MiB；Gemini 最多 14 张，单张及总量均为 12 MiB（均按解码后体积计算）。供应商可能要求更低限制。输出最多 10 张、每张最多 25 MiB，支持 PNG/JPEG/WebP/GIF 魔数识别。GIF 可作为输出保存，不作为上传参考图。

供应商总超时默认 600 秒，可用 `PROVIDER_TIMEOUT_SECONDS` 调整至 1–600 秒。HTTP 重定向不跟随，远程结果下载不转发生成请求的 Authorization。渠道 HTTP(S) 目标不设域名/IP/端口限制，这是已经接受的内网访问风险。

认证失败先重新登录；共享生成被拒绝先检查账号、渠道、模型启用状态和日额度；刷新目录失败不等于生成接口不可用。数据库/磁盘持久化失败会暂停派发，修复存储后重启，不要通过删除数据库或密钥“修复”。完整备份与运维步骤见 [部署指南](<DEPLOYMENT.md>)。
