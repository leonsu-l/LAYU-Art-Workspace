# Java 后端重构：已确认范围

用户于 2026-11-15 确认实施。先完成、验证现有功能迁移，再推进多用户功能。现有未提交的前端 Material 3 改动必须保留；本次不是另一次视觉重构。

## 阶段一

Java 21 + Spring Boot 替代 Node HTTP 后端；PostgreSQL 保存任务和图库索引，数据卷保存图片。保留两种生成协议、参考图、幂等提交、持久队列、完成收据恢复、结果下载、图库统计及按任务成组删除。未开始任务可重启恢复，已经请求供应商但没有结果收据的任务不自动重发。旧接口无兼容要求，旧业务数据不迁移。当前前端在必要处适配，不替换现有 UI 风格。

## 阶段二

- 用户名/密码/邀请码注册；邀请码仅管理员发放，无使用次数或有效期限制，可撤销；注册均为普通用户。仅登录且未禁用用户可生成。
- 部署端创建/恢复管理员；后台禁用/解禁普通用户、重置密码，重置后强制改密。普通用户的历史、提示词、图片仅本人可见；管理员看使用量和任务状态，不看私人内容。
- 一级选择站点共享/个人自定义渠道，下级为 OpenAI/Gemini 协议。密钥服务端加密，API 不返回原文。公网部署，用户明确要求 HTTP(S) 目标不设置域名/IP/端口限制，接受相关服务端请求风险。
- 模型目录 API 获取、缓存、定期/手动刷新；失败保留缓存。缺少发现 API 可由渠道管理者手填 ID。共享模型由管理员显式启用，不自动升级或换模型。
- 管理员模板仅含名称、协议和参数预设，不绑定模型/地址/密钥，不限制用户调整。支持现有协议字段，不提供任意 JSON/请求头编辑器。参数不被静态能力表静默改写。按用户+渠道+模型保存最近参数，跨设备同步，无个人模板管理。
- 管理员设置默认日任务额度、用户覆盖、无限额选项；共享渠道合并计数，私有渠道不消耗共享额度。未配置不开放共享生成。北京时间统计，管理员设置全站/单人并发与队列上限。受理预占，失败一律返还（包括已请求上游），幂等事件不能重复扣/退；返还站内额度不代表供应商退款。
- 提交时冻结渠道、密钥、模型与参数；密钥快照加密，任务终态清除。编辑不影响已提交任务；禁用用户/关闭渠道终止尚未执行的任务，已经请求上游的任务可收尾。
