# Cobalt Studio · Design Lab

工作台、图库、自定义渠道、账号和站点管理已接入现有应用。生产页面使用登录会话和 Java API；Design Lab 使用独立的示例数据，可单独预览加载、空态、错误和恢复场景。

## 启动

- **看设计**：在仓库根目录运行 `npm run dev:web`，打开 <http://127.0.0.1:5173/design-lab.html>。这个开发入口不需要后端。
- **用应用**：按[本地启动说明](<../README.md#启动>)配置数据库并启动 `npm run dev:api`，在另一终端运行 `npm run dev:web`，打开 <http://127.0.0.1:5173/>。首次生成前，管理员需配置共享渠道、启用模型和日额度，或由用户配置自己的私有渠道。

## 生产页面

| 页面 | 路由 | 已连接的行为 |
| --- | --- | --- |
| 创作工作台 | `/` | 选择渠道和模型、套用参数模板、上传参考图、提交与恢复同一任务、在胶卷中切换结果和下载原图 |
| 我的图库 | `/gallery` | 刷新云端作品、沉浸预览、键盘切图、下载、选中作品后确认整组删除 |
| 自定义渠道 | `/channels` | 编辑私有渠道、更新只写密钥、发现模型或手填模型 ID；编辑时密钥留空保留原值 |
| 账号 | `/login`、`/password` | 登录、邀请码注册、修改密码；管理员重置密码后，成员须先改密再进入工作台 |
| 站点管理 | `/admin` | 管理共享渠道、用户、邀请码、额度与队列、参数模板和使用统计 |

生产页面和原型共用[设计令牌](<../apps/web/src/studio/tokens.css>)、[交互控件](<../apps/web/src/studio/Controls.tsx>)和[图库视图](<../apps/web/src/studio/GalleryView.tsx>)。原型及场景开关留在开发入口，角色权限、配额、任务状态和删除结果由生产接口决定。

## 仅在 Design Lab 中预览

在「03 · 全站多页原型」中可评审以下场景：

- **工作台**：查看任务结果与胶卷的有效期；模拟恢复时收到 HTTP 410，清除待恢复提交，避免重复生成。
- **图库**：切换混排有效期、空图库、新图永久和图片 404。新图默认策略与每张作品的到期时间分开展示；失效图片可从列表移除，再刷新恢复。
- **站点管理**：除生产已有的六个栏目外，原型还提供「存储管理」和「问题日志」。可演示 R2 桶配置与凭据轮换、应用用量与 Cloudflare 统计对比、删除冲突，以及问题处理后复发重开。

## 集成验证

集成分支：`feat/design-lab-ui-integration`。在生产构建预览中，用隔离的 Java 后端、H2 和本机图片服务走通了：

- 管理员创建邀请码、设置共享额度、保存参数模板、创建共享渠道并刷新模型。成员可注册；普通成员访问 `/admin` 返回工作台，强制改密账号在改密前只能访问密码页。
- 一次任务提交取得两张 384 × 256 原图。工作台显示实际尺寸与请求尺寸的差异；图库仅选中一张，取消删除时两张保留，确认后同组两张作品与任务历史同时移除。
- 1440px 桌面与 390px 手机布局、主题切换、手机横滑切页，以及预览内的键盘切图和关闭后焦点恢复。

构建使用 `npm run build:web`；提交恢复、会话校验和界面逻辑用例可用 `npm run test:web` 复查。设计取舍见[决策记录](<design-decisions.md>)，当前路由与组件清单见[设计状态](<design-state.json>)。
